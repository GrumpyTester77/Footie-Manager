Creating Custom Strategy:
─────────────────────────
from strategies import MatchSimulationStrategy

class MyCustomStrategy(MatchSimulationStrategy):
    def simulate(self, match):
        print(f"Simulating {match.home_team.name} vs {match.away_team.name}")
        # Your simulation logic here
        for _ in range(5):  # 5 cycles
            # Update match state
            match.record_goal(match.home_team.name)
        print(match.get_result())
    
    def get_name(self):
        return "My Custom Strategy"

# Use it
strategy = MyCustomStrategy()
match = MatchFactory.create(arsenal, liverpool, strategy=strategy)
match.simulate()

ANTI-PATTERNS TO AVOID
═══════════════════════════════════════════════════════════════════════════

❌ Don't:  team_dict = {"Arsenal": ["Player1", "Player2"]}
✓  Do:     team = Team("Arsenal"); team.add_player(player)

❌ Don't:  from Match import match_day; match_day(...)
✓  Do:     from strategies import RandomMatchStrategy
           match = MatchFactory.create(home, away, strategy=strategy)
           match.simulate()

❌ Don't:  global teams, global managers, global players
✓  Do:     game = GameManager()  # Single source of truth

❌ Don't:  try: data = api(); except: data = csv()  (repeated code)
✓  Do:     repo = RepositoryFactory.create_player_repository()

❌ Don't:  Match(team1, team2)  # Direct creation, no validation
✓  Do:     MatchFactory.create(team1, team2)  # Validated

❌ Don't:  if match_type == "quick": ... elif match_type == "random": ...
✓  Do:     strategy = StrategyFactory.create(match_type)

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════

Q: "GameManager() returns same instance"
A: That's correct! It's a Singleton. Same instance everywhere.
   Reset with: game.reset()

Q: "Can I use CSV and Database at same time?"
A: RepositoryFactory creates one or the other, not both.
   To use both, create separate repositories:
   
   csv_repo = PlayerRepository(CSVDataSource())
   db_repo = PlayerRepository(DatabaseDataSource())

Q: "How do I add a new strategy?"
A: Create class, implement simulate() and get_name()
   Register: StrategyFactory._strategies["name"] = YourStrategy
   Use: StrategyFactory.create("name")

Q: "What if factory validation rejects my input?"
A: Check error message - it will tell you what's wrong
   ValueError is raised for invalid inputs
   
   Valid positions: GK, DF, MF, FW
   Non-empty team names, manager names
   Different home/away teams for matches

Q: "Match.simulate() does nothing?"
A: Set strategy first: match.set_strategy(strategy)
   Or pass to factory: MatchFactory.create(..., strategy=strategy)

Q: "How do I test without actual CSV file?"
A: Use mock strategy:
   
   class MockStrategy(MatchSimulationStrategy):
       def simulate(self, match):
           match.record_goal(match.home_team.name)
       def get_name(self):
           return "Mock"
   
   match = MatchFactory.create(home, away, strategy=MockStrategy())
