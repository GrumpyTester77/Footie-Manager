✓ WHAT THIS FIXES:

BEFORE (Problems):
├─ Teams created directly: Team("Arsenal", manager)
├─ No validation - could create invalid teams
├─ Matches created inconsistently
├─ Logic scattered through Main.py, Teams.py, Match.py
├─ Hard to add initialization logic (colors, jerseys, etc.)
├─ Same team match possible (no validation)
└─ Duplicated creation code

AFTER (Solutions):
├─ Teams created through factory: TeamFactory.create()
├─ Automatic validation (empty names rejected)
├─ Consistent Match creation via MatchFactory
├─ All creation logic centralized in factories.py
├─ Easy to add defaults (colors, etc.) - add once, everywhere uses it
├─ Validation prevents invalid objects (same team match impossible)
└─ One place to change creation logic
